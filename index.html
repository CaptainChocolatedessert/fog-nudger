Fog Nudger

The map already shows where the walls are. Stop drawing them again.

An Owlbear Rodeo extension that creates walls and fog regions from the walls drawn on a map image. What it finds is a proposal to check and correct, since a doorway and a gap in the linework look alike.

Works with Owlbear Rodeo's own fog. Compatible with Dynamic Fog, which uses the same walls for line of sight.

Pre-release. Nothing to install yet.
