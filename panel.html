Connecting…

Read the map is where the picture becomes walls: choose the image, decide what counts as ink, correct it by hand, and save the result. It has to be its own surface because the answers are per-pixel verdicts, which only a picture can carry.

Edit the walls opens what was saved and lets you move, draw and erase them by hand. Going back to reading the map is not destructive — only saving from there replaces the walls, and it says so first.

Both put the result straight on the fog layer, replacing whatever we put there before. There is no staging step. So a hand edit to one of our fog items does not survive the next write — edit it in one of these instead.

Our fog

Takes out everything this extension put in the scene, and the saved walls behind it, and leaves anything you drew by hand alone. Only needed to stop using the extension on a map; an ordinary re-run replaces its own output.

Diagnostics

Trace, emit nothing runs the whole chain and writes the numbers to the log — coverage, region counts, and the area check, which is two independent computations of the same figure agreeing. The workspace draws the same partition; this is the only thing that reports it in numbers. What is here? is no longer a button: click the map in the workspace.

Workspace probe puts up an opaque full-screen sheet that keeps its own input, which is what the workspace is drawn on. Drag on the pad, spin the wheel, right-click, and type in the box; the sheet reports whether Owlbear moved underneath, which you cannot see, because the sheet is covering it. Kept because its leak detector is the only way to re-check that a change has not started letting input through to Owlbear.
